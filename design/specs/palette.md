This comprehensive design system standardizes the portal's UI components, typography, and data visualizations into distinct, purpose-driven color categories.

**Predominant Functional Tones (Blue & Gray)**
These colors form the architectural foundation of the portal, ensuring a low-fatigue environment that emphasizes structural hierarchy.

| Color Name | Hex Code | Visual | UI Application (Where to use) |
| --- | --- | --- | --- |
| **Dark Navy Blue** | `#001C3E` | ████ | Primary UI: Main App Navigation, Active Tabs, Primary Action Buttons ("Sign Out"). |
| **Cool Medium Gray** | `#666666` | ████ | Secondary UI: Inactive Tab states ("In the pipeline"), UI borders, Chart Gridlines. |
| **Light Page Gray** | `#F7F7F7` | ████ | Base Canvas: The overarching portal background behind the content cards. |
| **Off-White** | `#FFFFFF` | ████ | Content Canvas: Dashboard cards, dropdown menus, filter panel backgrounds. |
| **Soft Shadow Gray** | `#E0E0E0` | ████ | Elevation: Card drop shadows, subtle table dividers, structural borders. |

**Strategic Accent & Text Tones**
This tier governs readability and categorization, ensuring text and metadata do not compete with critical financial alerts.

| Color Name | Hex Code | Visual | UI Application (Where to use) |
| --- | --- | --- | --- |
| **Text Black** | `#1A1A1A` | ████ | Primary Typography: KPI Titles, Main Headings (H1/H2), Core Data Values. |
| **Text Gray** | `#444444` | ████ | Secondary Typography: Subtitles, Dense Body Text inside cards, Table Row Data. |
| **Standard Tag Gray** | `#D9D9D9` | ████ | Categorization: System requirement tags (e.g., "SAP", "FileZilla"), Neutral UI chips. |
| **Indigo Indicator** | `#4A1A7D` | ████ | Interaction: Hover states, active text underlines, selected filter highlights. |

**Performance & Financial Health Tones**
Reserved exclusively for status flags and high-level KPIs, these semantic colors trigger immediate executive recognition of success or failure.

| Color Name | Hex Code | Visual | UI Application (Where to use) |
| --- | --- | --- | --- |
| **Positive Green** | `#2E8B57` | ████ | Success States: Positive KPI numbers, +ROI text, "Stable/Live" status indicator dots. |
| **Critical Alarm Red** | `#CC0000` | ████ | Alert States: Negative KPI variances, -ROI text, "Failed/At Risk" status indicator dots. |
| **Neutral Mid-Gray** | `#A0A0A0` | ████ | Pending States: Cash flow placeholders, "Pending Validation" status indicator dots. |
